# Plan 3 — Schrijven (writing) · priority 3

## The exam
- **Pen and paper**, 40 minutes, 4 tasks (official). Checked by a person; result takes about 16 weeks.
- From the 3 DUO practice exams, the 4 tasks are always of these kinds:
  1. **Short e-mail, formal** — e.g. move an appointment with your teacher (`Beste mevrouw de Groot,`).
  2. **Short e-mail, informal** — e.g. ask a colleague to swap a shift (`Hallo Farida,`).
  3. **Form** — name, address, postcode, phone, tick a box + 1–2 short open questions.
  4. **Short text, at least 3 sentences** — e.g. a party you celebrate, for the neighbourhood paper.
- Every task gives you 3 bullet points. **Answer all 3.** That is most of the score.

## What makes you pass
- One simple sentence per bullet point. Subject + verb + rest. `Ik kan morgen niet komen.`
- Whole sentences, capital letter, full stop. Short is fine; missing a bullet is not.
- Learn 12 fixed sentences and 2 e-mail frames by heart. Then you only fill the gaps.
- The reason can always be the same: `omdat ik ziek ben` / `want ik moet werken` / `omdat ik naar de dokter moet`.
- Spelling mistakes are accepted if the word is still clear. Write by hand when you practise — the exam is on paper.

## The two frames (learn by heart)

```
Beste meneer / mevrouw [naam],            Hallo [naam],

Ik schrijf u omdat ...                    Ik heb een vraag.
Ik kan [dag] niet komen, want ...         Ik kan [dag] niet werken, want ...
Kan ik op [dag] om [tijd] komen?          Kun jij [dag] voor mij werken?
                                          Ik kan wel op [dag] werken.
Alvast bedankt.                           Alvast bedankt!
Met vriendelijke groet,                   Groetjes,
[naam]                                    [naam]
```

## The ladder (24 lessons, 10 minutes each)

| Trede | Lessons | You write | How |
|-------|---------|-----------|-----|
| 1 | S1–S4 | copy words and sentences, capital + full stop | copy, then from memory |
| 1 | S5–S7 | your own data: naam, adres, postcode, geboortedatum, telefoon | form trainer |
| 2 | S8–S12 | build a sentence from loose word tiles (verb in 2nd place) | drag the tiles, then type it |
| 2 | S13–S15 | `niet/geen`, `want/omdat`, a time in the sentence | gap-fill, then type |
| 3 | S16–S19 | the two e-mail frames, 6 situations each | fill the frame → write it without the frame |
| 3 | S20–S22 | 3-sentence text: feest, weekend, mijn buurt, mijn werk, vakantie | answer 3 questions = 3 sentences |
| 4 | S23–S24 | full task sets, 40 minutes, **on paper** | then compare with the model answer + checklist |
| ✔ | Toets | the 3 DUO writing PDFs (already downloaded) | on paper, timed |

## Lesson page
1. **Voorbeeld** — the task and a model answer; the three bullet points and the three answer sentences are colour-matched.
2. **Bouw** — rebuild the model answer from word tiles.
3. **Schrijf** — type your own. Instant checks, no AI needed: every bullet has a required pattern (e.g. a day name, `want|omdat`, a question mark), capital letters, full stops, greeting and closing.
4. **Papier** — write the same answer by hand, then tick the checklist yourself:
   ☐ alle 3 punten ☐ aanhef ☐ afsluiting + naam ☐ hele zinnen ☐ hoofdletter en punt.
5. Optional: paste your answer to Claude/ChatGPT with the prompt on the page ("corrigeer op A2-niveau, leg kort uit") for real feedback. Local grammar check alternative: [LanguageTool](https://github.com/languagetool-org/languagetool) (open source, supports Dutch) — optional, heavy (Java).
